# Автотесты «Раздачи ЗП»

Тесты открывают `index.html` в браузере Chromium и проверяют, что сайт работает так же, как исходная версия (коммит `aac1f26`, ветка `stable-before-split`). На сам сайт и на GitHub Pages папка `tests/` не влияет.

## Запуск

Нужны Node.js 18+ и Playwright с Chromium:

```
cd tests
npm install
npm install --no-save playwright && npx playwright install chromium   # если Playwright ещё не установлен
node run.js                    # все проверки
node run.js calc               # только одна группа: structure | calc | baseline
node run.js --loose-screens    # отличия скриншотов не считать ошибкой (другой компьютер — другие шрифты)
```

Код выхода 0 — всё прошло, 1 — есть ошибки. Отличающиеся снимки и скриншоты сохраняются в `tests/out/` (в git не попадает).

## Что проверяется

| Группа | Файл | Что проверяет |
|---|---|---|
| Структура кода | `suites/structure.js` | нет повторно объявленных функций и переменных во всех скриптах; набор из 176 глобальных имён (131 функция, 45 переменных) совпадает с эталоном; пути к файлам относительные и существуют; после загрузки все функции доступны, ошибок в консоли нет |
| Расчёты | `suites/calc.js` | контрольный катер 112 кг; смены 26.10 и 13.10 сверяются с листами Google Таблицы (кг, начислено, к выдаче, банк); ставки, салат, ручной банк, неравное присутствие на этапах, распределение аванса, закрытие смены |
| Сравнение с эталоном | `suites/baseline.js` | 6 сценариев (пустое устройство, текущая смена, архив и журнал, старый формат данных, загрузка смены из таблицы, режим сотрудника): после каждого шага HTML, localStorage и запросы к Apps Script совпадают с эталоном; скриншоты 5 вкладок на 360/390/414 px; нет горизонтальной прокрутки |

## Условия прогона

- Время зафиксировано (02.11.2026 12:00 МСК), часовой пояс Europe/Moscow, `Math.random` предсказуем — результаты одинаковы при каждом запуске.
- Запросы к Google Apps Script перехватываются и отвечаются имитацией (`lib/app.js`); в настоящую таблицу ничего не отправляется. Любые другие внешние запросы блокируются и считаются ошибкой.
- Облако Claude для режима сотрудника имитируется.

## Тестовые данные

`fixtures/*.json` — **обезличенные** данные: имена условные (Аз, Буки, Веди…), PIN — `0000`. Кг, ставки и суммы смен 26.10.2026 и 13.10.2026 взяты из листов Google Таблицы, чтобы проверять расчёт на реальных цифрах. Файлы пересоздаются командой `node fixtures/make.js`.

## Эталон

`baseline/` снят на исходной версии. Пересоздавать его (`node run.js --update`) можно только на ветке `stable-before-split`, иначе тесты перестанут ловить изменения. При рефакторинге эталон не меняется.
