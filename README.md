# razdacha-zp
Сайт «Раздача ЗП»

Мобильное одностраничное приложение для расчёта и выдачи зарплаты бригаде по сменам обработки катеров.
Сайт: https://leod4.github.io/razdacha-zp/ (GitHub Pages, ветка `main`). Сборка не нужна: файлы отдаются как есть.

## Структура файлов

```
index.html            разметка: <div id="app"> и подключение стилей и скриптов
css/style.css         все стили
js/utils.js           вспомогательные функции: форматирование, разбор чисел и дат, номиналы купюр
js/store.js           состояние приложения, localStorage, миграции данных, сохранение
js/calc.js            расчёты: кг на человека, ставки, банк, начисления, выплаты, раскладка купюр, табель
js/sheets.js          Google Таблица и Apps Script: отчёт смены, загрузка смены, журнал выплат
js/views.js           интерфейс: вкладки, нижнее меню, обработчики нажатий
js/app.js             запуск приложения (миграция данных, первая отрисовка)
apps-script/          код для Apps Script, привязанного к Google Таблице (сайт его не загружает)
tests/                автотесты (на сайт не влияют), см. tests/README.md
```

## Порядок подключения

Скрипты — обычные `<script src>` (не модули), подключаются в конце `<body>`, после `<div id="app"></div>`, строго в таком порядке:

```
<script src="js/utils.js?v=…"></script>
<script src="js/store.js?v=…"></script>
<script src="js/calc.js?v=…"></script>
<script src="js/sheets.js?v=…"></script>
<script src="js/views.js?v=…"></script>
<script src="js/app.js?v=…"></script>
```

- Все файлы работают в общей глобальной области: функции и переменные одного файла доступны в остальных.
- `js/app.js` подключается последним: только он запускает приложение, когда все функции уже загружены.
- Без `async`, `defer` и `type="module"`: приложение рисуется сразу при загрузке страницы; так же сайт открывается и прямо с диска.
- Пути относительные, поэтому сайт работает и по адресу `/razdacha-zp/` на GitHub Pages, и на локальном сервере.

## Версия файлов (`?v=`)

У всех ссылок на CSS и JS в `index.html` одна и та же метка версии, например `?v=20261103`. При каждом выпуске изменённых файлов меняйте её во всех семи ссылках сразу — иначе телефон может взять из кэша старые файлы вперемешку с новыми. Тесты проверяют, что метка у всех ссылок одинаковая.
